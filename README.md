# Barchemy MVP Starter Package

Barchemy — Where Every Pour Becomes a Story.
J.Bink is the AI bartender/chatbot and is not human.

This package contains the Expo/React Native starter, Supabase client foundation,
MVP screen flow, database SQL, CI configuration, and project documentation.

No private credentials are included. Never commit .env, service-role keys,
secret API keys, database passwords, or access tokens.

Core vertical slice:
Arrival → J.Bink → My Bar → Ask J.Bink → Recommendation → First Pour → Memory.
